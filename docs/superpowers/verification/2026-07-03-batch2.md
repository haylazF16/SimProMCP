## Bugs found by live verification (fixed + regression-tested)

1. **`jsonBlock` crash on 204 No Content** — `JSON.stringify(undefined)` → `truncate(undefined)` crashed `update_contact` echo. Fixed in `_shared.ts` (falls back to `"null"`), regression test added. This protected every write tool that echoes a PATCH response.
2. **Staff name shape** — staff rows carry flat `Name` (contractors AND some employees), not only `GivenName/FamilyName`. `get_staff_member` now falls back to `Name`. Verified live on both companies.

## Incident (disclosed)

The FIRST smoke run silently ran writes LIVE: the repo `.env` loads with `override: true` and
clobbered the harness's `SIMPRO_DRY_RUN=true`. One real record was created — **contact #65786
"Smoke Test" (company 4)** — before Simpro's own validation rejected the other creates
(422/404/500; no other mutations). Mitigations now in the harness: (a) canary gate refuses to
run writes unless a probe proves DRY RUN; (b) the incident is documented here.
**Cleanup pending:** contact #65786 needs deleting (delete via API was blocked by policy —
awaiting user decision; it can be removed in the Simpro web UI in seconds).

## Tenant payload caveats (from the accidental live attempt — useful data)

- `POST /leads/` — tenant requires a valid `Site` (422 without it). Tool supports `siteId` + `rawPayload`.
- `POST /storageDevices/` — tenant rejected `Type: "Vehicle"` (422 on `/Type`); check accepted values or omit Type / use rawPayload.
- `POST /stockTakes/` — returned 500 on a nonexistent storage device; use a real `storageDeviceId`.
